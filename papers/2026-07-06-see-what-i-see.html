See What I See, Know What I Think
— Read another agent's KV-cache: both what it sees and how it thinks— 다른 에이전트의 KV-cache를 읽는다: 그가 본 것과 생각한 것 모두

👥 Siyi Chen et al.외 9인 🏛 U. Michigan · NVIDIA 🗓 2026.06.11 📄 arXiv:2606.13594
⚡ TL;DR

Multi-agent systems mostly talk in text — a lossy, expensive decode-and-re-encode at every hop. Passing the sender's KV-cache instead is cheaper, but prior work only did it between identical models. This paper asks whether heterogeneous agents (different sizes) can be aligned well enough for real "mind reading" — and finds a duality: when the receiver still sees the question, only a sparse ~3.5% of the cache matters; when it doesn't ("context-unaware"), you need a dense ~87%. Their lightweight cross-model adapter densely aligns the sender cache into the receiver's latent space, matching or beating text at 2–3× lower compute, and staying strong in the context-unaware regime where text and prior cache methods collapse to chance.

멀티에이전트 시스템은 대개 텍스트로 소통한다 — 매 단계 손실 있고 값비싼 디코딩·재인코딩. 대신 송신자의 KV-cache를 넘기면 싸지만, 선행 연구는 동일 모델 사이에서만 했다. 이 논문은 이질적 에이전트(크기가 다른)를 진짜 "독심술"이 가능할 만큼 정렬할 수 있는가를 묻고, 이중성을 발견한다: 수신자가 질문을 여전히 볼 때는 캐시의 희소한 ~3.5%면 충분하지만, 못 볼 때("context-unaware")는 조밀한 ~87%가 필요하다. 이들의 경량 cross-model 어댑터는 송신 캐시를 수신자 잠재 공간으로 조밀하게 정렬해, 텍스트를 2~3× 낮은 연산으로 동등·능가하고, 텍스트·기존 캐시 기법이 우연 수준으로 붕괴하는 context-unaware 영역에서도 견고하다.

Why it matters왜 중요한가

The real bottleneck isn't "which latent to send" — it's whether two different models can share a latent language at all.

진짜 병목은 "어떤 잠재를 보내냐"가 아니라, 서로 다른 두 모델이 애초에 잠재 언어를 공유할 수 있느냐다.

KV-cache communication lets a receiver absorb a sender's context without parsing natural language — no decode, no re-encode. But a cache is written in each model's private geometry: different layer counts, head dimensions, and RoPE conventions. Prior latent-communication work sidestepped this by using duplicate copies of one model (homogeneous), or by only using the transferred cache to lightly steer a receiver that still had the input. This paper takes on the harder question — dense, cross-model alignment — and reframes it around how much information the channel must actually carry.

KV-cache 통신은 수신자가 자연어를 파싱하지 않고 송신자의 맥락을 흡수하게 한다 — 디코딩도, 재인코딩도 없다. 그러나 캐시는 각 모델의 사적인 기하로 쓰여 있다: 층 수·헤드 차원·RoPE 방식이 다르다. 선행 잠재 통신 연구는 이를 한 모델의 복제본(동질)이나, 입력을 여전히 가진 수신자를 가볍게 조종(steering)하는 데만 캐시를 써서 회피했다. 이 논문은 더 어려운 질문 — 조밀한 cross-model 정렬 — 을 정면으로 다루고, 채널이 실제로 얼마나 많은 정보를 날라야 하는지로 재정의한다.

The core finding — sparse to reason, dense to know핵심 발견 — 추론엔 희소, 앎엔 조밀

Before designing anything, the authors ask an information question with a compressed-sensing probe: perturb the sender's attention heads with 200 random masks, use Lasso to score which KV groups actually carry the signal, then sweep how many of the 288 groups you must keep. The answer splits sharply by regime.

무언가를 설계하기 전에, 저자들은 압축 센싱(compressed sensing) 프로브로 정보 질문을 던진다: 송신자 어텐션 헤드를 200개 랜덤 마스크로 교란하고, Lasso로 어떤 KV 그룹이 실제로 신호를 나르는지 점수 매긴 뒤, 288개 그룹 중 몇 개를 남겨야 하는지 훑는다. 답은 영역에 따라 극명하게 갈린다.

This duality is the paper's thesis: context-aware evaluation is a weak test (the receiver already holds the answer's context, so the channel only nudges it), while context-unaware is the honest one — the cache must be a self-contained carrier of both evidence and reasoning. A good heterogeneous adapter therefore has to preserve dense information, not just steer.

이 이중성이 논문의 논지다: context-aware 평가는 약한 시험(수신자가 이미 답의 맥락을 쥐고 있어 채널은 살짝 밀 뿐)이고, context-unaware가 정직한 시험 — 캐시가 증거와 추론 모두의 자족적 운반체여야 한다. 따라서 좋은 이질 어댑터는 단순 조종이 아니라 조밀한 정보를 보존해야 한다.

Idea: a cross-model cache transformation아이디어: cross-model 캐시 변환

① 정렬

Position-disentangled, layer-mapped

RoPE entangles content with position, so the sender cache is first passed through RemoveRoPE; after transformation the receiver's own AddRoPE restores native positions. Different depths are bridged by a monotonic map a(l) = round(l·(LS−1)/(LR−1)), keeping the low→high feature progression.

RoPE는 내용과 위치를 얽으므로, 송신 캐시를 먼저 RemoveRoPE에 통과시키고, 변환 후 수신자의 AddRoPE가 native 위치를 복원한다. 서로 다른 깊이는 단조 사상 a(l) = round(l·(LS−1)/(LR−1))로 이어, 저→고 특징 진행을 유지한다.

② 변환 + 선택

Per-head gated MLPs

Each receiver KV group gets its own per-token MLPs for keys and values that expand the head dim 16× then project to the receiver's dimension, with a learnable gate γ∈[0,1] that lets the model prioritize the reasoning-carrying heads the compressed-sensing analysis flagged — dense capacity, selective emphasis.

각 수신자 KV 그룹은 key·value 각각에 대해 토큰별 MLP를 가지며 헤드 차원을 16× 확장 후 수신자 차원으로 사영한다. 학습형 게이트 γ∈[0,1]가 압축 센싱이 짚은 추론 담당 헤드를 우선하게 한다 — 조밀한 용량에 선택적 강조.

What to take away그래서, 가져갈 것

🔀

Duality is the idea. "How much cache to send" has no single answer — it's sparse for steering, dense for standing alone. Naming this splits latent communication into two very different problems.

핵심은 이중성. "캐시를 얼마나 보낼까"엔 단일 답이 없다 — 조종엔 희소, 홀로 서기엔 조밀. 이를 명명하며 잠재 통신을 매우 다른 두 문제로 가른다.

🌉

A real heterogeneous bridge. De-RoPE + layer map + per-head gates transfer a cache across different-sized models — no shared input assumed, unlike prior steering-only methods.

진짜 이질 다리. RoPE 해제 + 층 사상 + 헤드 게이트로 크기가 다른 모델 간 캐시를 전이한다 — 기존 조종 전용 기법과 달리 공유 입력을 가정하지 않는다.

⚡

Cheaper because the sender never talks. Killing sender decoding and receiver re-encoding is where the 2–3× comes from — a structural win, not a tuning trick.

송신자가 말하지 않아 싸다. 송신자 디코딩과 수신자 재인코딩을 없앤 것이 2~3×의 출처 — 튜닝 요령이 아닌 구조적 이득.

🕵️

Honest test, uncomfortable question. The context-unaware regime is a stricter benchmark the field mostly skipped — but transferring "what the sender sees" without the prompt is also a privacy surface.

정직한 시험, 불편한 질문. context-unaware는 분야가 대체로 건너뛴 더 엄격한 벤치마크다 — 다만 프롬프트 없이 "송신자가 본 것"을 넘기는 건 프라이버시 표면이기도 하다.

⚠️ One critical note: "Heterogeneous" here means three sizes of one family (Qwen3-4B/8B/14B) — same tokenizer, same architecture — so the hardest cross-family / cross-tokenizer case is untested. In-domain wins (GSM8K, MATH) are on the very tasks the adapter trained on; on held-out OOD sets Ours often only ties or slightly trails text. And a dense KV payload is 20–30 MB per message vs. a few hundred bytes of text — a bandwidth cost the headline TFLOPs quietly excludes.
